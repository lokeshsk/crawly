Zero-Setup Downloads for Windows & Linux / WSL

Normal users never need to run pip install or touch requirements.txt. All libraries (pypdf, rich, requests, beautifulsoup4) and config.json are pre-bundled in dist/.

🪟 Windows & Linux Universal Bundle

Single 2.5 MB archive containing crawly.pyz, crawly.bat (Windows), crawly (Linux/WSL), and config.json with all libraries baked inside.

dist\crawly.bat

🐧 Linux & WSL Standalone Binary

Compiled native x86_64 executable built with PyInstaller. Runs immediately even on machines without Python installed.

./dist/crawly-linux-x86_64

⚡ Native Windows .EXE Release

Compiled automatically via GitHub Actions on every release tag for zero-dependency execution on Windows 10/11.

.\dist\crawly-windows-x86_64.exe

Built for Serious Literature Reviews

Everything a researcher needs from initial keyword search to full-text synthesis and LaTeX citation export.

🌐 8+ Legal Open-Access APIs

Queries OpenAlex, Semantic Scholar, arXiv, Europe PMC / PubMed Central, Crossref, DOAJ, HAL Open Archive, and OpenAIRE concurrently with live rich progress bars.

📥 Smart DOI & PDF Waterfall

Resolves missing DOIs from existing CSVs via URL parsing, OpenAlex, and Crossref, then checks Unpaywall, arXiv preprints, Europe PMC, and OpenAlex OA with strict %PDF- verification.

🤖 3 AI Literature Review Modes

Choose between Mode 1 (Structured Per-Paper Summaries), Mode 2 (Cross-Paper Synthesis & Comparison Matrix), and Mode 3 (Citation-Grounded RAG Q&A over PDFs).

⚙️ Single config.json Setup

Configure Ollama, LM Studio, OpenAI-compatible servers (vLLM, Groq, OpenRouter, DeepSeek), Gemini, Claude, temperature, and default limits in one labeled config.json file.

📚 Automatic BibTeX (.bib) Export

Every search and download batch automatically exports a clean .bib file ready for Zotero, Mendeley, EndNote, or Overleaf/LaTeX manuscripts.

🩺 System & API Health Doctor

Run crawly doctor anytime to verify connectivity across all 8 scholarly APIs and your local or cloud AI model server in seconds.

Interactive CLI Command Builder

Customize your research workflow and copy the exact command for Windows or Linux/WSL.

./dist/crawly pipeline "synthetic aperture radar deep learning" -o sar_review --limit 10 --mode all
